# 炁体源流 - 张至顺道长著作

这是一个展示《炁体源流》全书内容的网站，将原书 512 页图片整理成易于浏览的网页格式。

## 网站结构

```
/workspace/
├── index.html          # 首页
├── chapter-1.html      # 第一章：基础理论 (第 0-127 页)
├── chapter-2.html      # 第二章：修炼方法 (第 128-255 页)
├── chapter-3.html      # 第三章：实践应用 (第 256-383 页)
├── chapter-4.html      # 第四章：心得体会 (第 384-511 页)
├── gallery.html        # 图片浏览页面
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── main.js         # JavaScript 脚本
└── images/             # 图片目录 (512 张图片)
    ├── page_0000.jpg
    ├── page_0001.jpg
    ├── ...
    ├── page_0511.jpg
    └── index.json      # 图片索引文件
```

## 功能特点

### 1. 章节浏览
- 全书分为 4 个章节，每章约 128 页
- 支持上一页/下一页翻页
- 支持键盘左右键快速翻页
- 提供快速跳转功能

### 2. 图片浏览
- 画廊模式展示所有 512 页图片
- 支持按章节筛选
- 支持自定义页码范围筛选
- 点击图片可放大查看（灯箱效果）
- 灯箱支持键盘导航（Esc 关闭，左右键切换）

### 3. 响应式设计
- 支持电脑、平板、手机等多种设备
- 自适应屏幕尺寸

## 使用方法

### 本地浏览
直接用浏览器打开 `index.html` 文件即可。

### 使用本地服务器（推荐）
```bash
# Python 3
cd /workspace
python3 -m http.server 8000

# 然后在浏览器访问 http://localhost:8000
```

### Node.js
```bash
npx serve /workspace
```

## 文件说明

- `index.html` - 网站首页，介绍书籍和章节目录
- `chapter-X.html` - 各章节阅读页面
- `gallery.html` - 全书图片浏览页面
- `css/style.css` - 全局样式文件
- `js/main.js` - 通用 JavaScript 功能
- `images/` - 存放所有书页图片
- `images/index.json` - 图片索引文件（JSON 格式）
